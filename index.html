AI Customer Support Chatbot Cloud & AI

A multi-path customer support chatbot for a fictional online shop built on Amazon Bedrock Flows, with three routing paths: bug reports routed through a Bedrock Agent to AWS Lambda to create support tickets in DynamoDB; platform FAQ questions handled via an embedded FAQ prompt; and unresolved requests redirected to a human support line. Includes flow accuracy evaluation using Bedrock Evaluations (LLM-as-a-judge) against a custom eval dataset, validating routing correctness across all three paths. Deployed via AWS CloudFormation.

AWS Bedrock Flows Bedrock Agents Bedrock Evaluations AWS Lambda DynamoDB CloudFormation Amazon Nova
AI Customer Support Agent (AgentCore) Cloud & AI

A production-style AI customer support agent for an e-commerce platform built with Amazon Bedrock AgentCore and the Strands Agents SDK. Tracks orders and processes refunds via Lambda functions exposed as MCP tools through AgentCore Gateway; answers product and policy questions via RAG against a Bedrock Knowledge Base; remembers customer names and preferences across sessions using AgentCore long-term memory; calculates loyalty-tier discounts via a sandboxed Code Interpreter; and browses live web pages via the AgentCore Browser tool. Includes CloudWatch error-rate monitoring and IAM role debugging across local and deployed environments. Deployed and verified end-to-end via agentcore invoke — 5 of 6 core test scenarios passing on the live AWS runtime, with the sixth blocked by an account-level Service Control Policy outside the project's control.

Python Strands Agents SDK Bedrock AgentCore Amazon Nova Lite AWS Lambda API Gateway Bedrock Knowledge Bases MCP boto3 CloudWatch
